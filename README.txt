VINTAGE v12
============
Оновлена головна сторінка в стилі наданого макета:
- темна Minecraft/industrial атмосфера
- великий центральний логотип
- золоті акценти
- панель статусу сервера
- 4 інформаційні картки
- Discord / Кабінет у верхньому меню
- адаптивна мобільна версія
- збережено Supabase, кабінет, whitelist, чат і гайд
- виправлено можливий JS-crash на сторінках без auth UI

Для оновлення через GitHub:
1. Add file -> Upload files
2. Замініть index.html і style.css та інші змінені файли
3. Commit changes
4. Зачекайте Cloudflare Pages
5. Ctrl+F5 у браузері
